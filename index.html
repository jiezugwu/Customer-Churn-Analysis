Can customer data predict churn?

A retention team wanted to target offers using the customer details they already held. I tested whether those details could actually identify who was likely to leave.

  • Validated 2,000 customer records in MySQL — complete, no duplicates.
  • Compared churn across 31 segments, with uncertainty ranges.
  • Built a logistic-regression model in Python (pandas, scikit-learn) against pre-set success criteria and a 30-run noise benchmark.
  • Visualised the results in a Tableau dashboard designed so stakeholders can't mistake noise for a pattern.
  • Recommended a randomised retention-offer pilot instead of a model that would only be guessing.
